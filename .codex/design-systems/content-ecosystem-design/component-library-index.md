## Excluded Internal Components

Do not use components whose names start with `_`, including examples such as:
- `_select-option-list-wrapper`
- `_tab`
- `_fold-icon`
- `_Nav-TabItem`
- `_Media/Video`
- `_media-player`
- `_AI_result`
- `_card_attr`
- `_comp_Radio`
- `_Sidebar Item`
- `_folder-icon`
- Playground components such as `_Sample Card`, `_media`, `_nav-icon`, `_play`, `_expanded`, `_addistional-info`
